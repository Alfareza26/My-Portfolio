## 🌌 Tentang Proyek Ini
Sebuah situs web portofolio pribadi yang **bold**, **responsif**, dan berenergi tinggi (*high-energy*). Terinspirasi dari estetika desain modern yang mengintimidasi secara visual, website ini menggabungkan presisi teknis dengan estetika *playful* untuk membangun produk digital yang tidak hanya bekerja—tetapi juga *bergetar* (*vibrate*).

Proyek ini merupakan *upgrade* dari portofolio statis (HTML/CSS/JS) menjadi aplikasi **Single Page Application (SPA)** yang dinamis menggunakan **React** dan **Vite**, dilengkapi dengan animasi *smooth* dari **Framer Motion** dan styling *utility-first* dari **Tailwind CSS**.

## ⚡ Fitur Utama
- 🌌 **High-Octane UI/UX**: Tipografi raksasa (*massive typography*), aksen warna neon, dan efek *text-glow*.
- ✨ **Micro-Interactions**: Animasi *scroll reveal*, *hover effects*, dan transisi halaman yang halus.
- 📱 **Mobile-First Responsive**: Dioptimalkan secara sempurna untuk layar HP, termasuk *Hamburger Menu* animasi dan *layout* yang adaptif.
- 🧩 **Component-Based Architecture**: Kode yang bersih, modular, dan mudah di-*maintain* menggunakan React Components.
- 🚀 **Lightning Fast**: *Build tool* Vite memastikan *Hot Module Replacement* (HMR) instan saat pengembangan.

## 🚀 Cara Menjalankan di Lokal (*Local Setup*)

Pastikan Anda telah menginstal **Node.js** dan **Git** di komputer Anda.

```bash
# 1. Clone repository ini
git clone https://github.com/Alfareza26/My-Portfolio.git

# 2. Masuk ke direktori proyek
cd My-Portfolio

# 3. Masuk ke folder frontend (client)
cd client

# 4. Instal semua dependencies
npm install

# 5. Jalankan server development
npm run dev
```

Buka browser dan akses `http://localhost:5173` untuk melihat website berjalan secara lokal.

## 🌐 Deployment
Proyek ini di-deploy secara otomatis menggunakan **Vercel** melalui integrasi GitHub. Setiap *push* ke branch `main` akan memicu *deployment* baru.
